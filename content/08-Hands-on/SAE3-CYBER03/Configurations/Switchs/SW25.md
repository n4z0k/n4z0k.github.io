# SW25
---

> Switch · Catalyst 2950 · site m · [[SAE3-CYBER03 - Accueil|Accueil]]

## Rôle

Switch unique du site m. VLAN 50 (serveurs, ports 21-23), VLAN 150 (clients publics, ports 11-20), VLAN 192 (clients privés, ports 1-10, protégés par **802.1X**), trunk 802.1Q vers [[R25]] sur le port 24. Il joue le rôle de **NAS RADIUS** (50.50.25.250, dans le VLAN 50, avec [[S25]]) ; syntaxe 2950 (`radius-server host`, `dot1x port-control auto`).

## Adresses

- Vlan50 : 50.50.25.250/24 (NAS RADIUS)

## Voisins

- [[R25]] — port 24 (trunk 802.1Q VLAN 50,150,192) ↔ Fe0/0 du R25
- [[S25]] — ports 21-23 (VLAN 50), eth0 de S25
- [[D25]] — ports 11-20 (VLAN 150), eth0 de D25
- [[G25]] — ports 1-10 (VLAN 192, 802.1X), eth0 de G25

## Configuration (avec prompt)

```cisco
Switch>enable
Switch#configure terminal
Switch(config)#hostname SW25
SW25(config)#no ip domain-lookup
SW25(config)#service password-encryption
SW25(config)#enable secret Sae3Cyber!
SW25(config)#username admin privilege 15 secret Sae3Cyber!
SW25(config)#banner motd #Acces reserve - SAE3-CYBER03 - SW25#
SW25(config)#ip domain-name sae3cyber03.iut
SW25(config)#vtp mode transparent
!
! ---------- VLAN ----------
SW25(config)#vlan 50
SW25(config-vlan)#name SERVEURS-PUBLICS
SW25(config-vlan)#exit
SW25(config)#vlan 150
SW25(config-vlan)#name CLIENTS-PUBLICS
SW25(config-vlan)#exit
SW25(config)#vlan 192
SW25(config-vlan)#name CLIENTS-PRIVES
SW25(config-vlan)#exit
!
! ---------- 802.1X : authentification par le serveur RADIUS du site ----------
SW25(config)#aaa new-model
SW25(config)#aaa authentication login default local
SW25(config)#aaa authentication dot1x default group radius
SW25(config)#aaa authorization network default group radius
SW25(config)#dot1x system-auth-control
! Le 2950 ne connait pas la syntaxe "radius server <nom>" : syntaxe classique
SW25(config)#radius-server host 50.50.25.1 auth-port 1812 acct-port 1813 key RadiusSae3
!
! ---------- Ports d'acces ----------
SW25(config)#interface range FastEthernet0/1 - 10
SW25(config-if-range)#description Clients prives - VLAN 192 (802.1X)
SW25(config-if-range)#switchport mode access
SW25(config-if-range)#switchport access vlan 192
SW25(config-if-range)#dot1x port-control auto
SW25(config-if-range)#spanning-tree portfast
SW25(config-if-range)#exit
SW25(config)#interface range FastEthernet0/11 - 20
SW25(config-if-range)#description Clients publics - VLAN 150
SW25(config-if-range)#switchport mode access
SW25(config-if-range)#switchport access vlan 150
SW25(config-if-range)#spanning-tree portfast
SW25(config-if-range)#exit
SW25(config)#interface range FastEthernet0/21 - 23
SW25(config-if-range)#description Serveurs publics - VLAN 50
SW25(config-if-range)#switchport mode access
SW25(config-if-range)#switchport access vlan 50
SW25(config-if-range)#spanning-tree portfast
SW25(config-if-range)#exit
!
! ---------- Trunk vers R25 ----------
SW25(config)#interface FastEthernet0/24
SW25(config-if)#description Trunk 802.1Q vers R25 Fe0/0
SW25(config-if)#switchport mode trunk
SW25(config-if)#switchport trunk allowed vlan 50,150,192
SW25(config-if)#exit
!
! ---------- Adresse du NAS : dans le VLAN des serveurs (comme le VLAN "radius" du TP5) ----------
! Pas dans le VLAN 192 controle par 802.1X
SW25(config)#interface Vlan1
SW25(config-if)#shutdown
SW25(config-if)#exit
SW25(config)#interface Vlan50
SW25(config-if)#ip address 50.50.25.250 255.255.255.0
SW25(config-if)#no shutdown
SW25(config-if)#exit
SW25(config)#ip default-gateway 50.50.25.254
!
! ---------- Acces console / SSH ----------
SW25(config)#crypto key generate rsa general-keys modulus 1024
SW25(config)#ip ssh version 2
SW25(config)#line console 0
SW25(config-line)#logging synchronous
SW25(config-line)#login authentication default
SW25(config-line)#exit
SW25(config)#line vty 0 4
SW25(config-line)#login authentication default
SW25(config-line)#transport input ssh
SW25(config-line)#exit
SW25(config)#end
SW25#write memory
```
