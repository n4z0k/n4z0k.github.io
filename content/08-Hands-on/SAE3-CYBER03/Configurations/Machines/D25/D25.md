# D25
---

> Client · Debian 12 · site m · [[SAE3-CYBER03 - Accueil|Accueil]]

## Rôle

Client **public** du site m (VLAN 150), adresse fixe, sans NAT. Sert aux tests d'accès aux serveurs ([[S25]], [[S26]]) et à la lecture de la vidéo depuis le site d'en face.

## Adresses

- eth0 : 150.150.25.1/24
- passerelle : 150.150.25.254

## Voisins

- [[SW25]] — eth0 ↔ ports 11-20 (VLAN 150)
- [[R25]] — passerelle par défaut 150.150.25.254 (Fe0/0.150)

## Configuration (avec prompt)

> Seule source de cette config : plus de fichier `.txt` pour les machines. Pour copier-coller, retirer le prompt `root@D25:~#`.

```bash
# =====================================================================
# D25 - Client public du site m - Debian 12 - configuration a chaud (root)
# =====================================================================
# ---------- Adressage IP (a chaud) ----------
root@D25:~#ip link set eth0 up
root@D25:~#ip addr add 150.150.25.1/24 dev eth0
root@D25:~#ip route add default via 150.150.25.254 dev eth0
root@D25:~#ip addr show eth0
root@D25:~#ip route
```
