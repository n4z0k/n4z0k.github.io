# G26
---

> Client · Debian 12 · site n · [[SAE3-CYBER03 - Accueil|Accueil]]

## Rôle

Client **privé** du site n (VLAN 192). Authentification **802.1X** (EAP-MD5) auprès de [[S26]] via [[SW26-2]], puis adresse par DHCP. NAT sur [[R26]] pour joindre l'autre site.

## Adresses

- eth0 : DHCP 192.168.26.1 à .128
- passerelle : 192.168.26.254

## Voisins

- [[SW26-2]] — eth0 ↔ ports 1-10 (VLAN 192, 802.1X)
- [[R26]] — passerelle par défaut 192.168.26.254 (Fe0/0.192)

## Configuration (avec prompt)

> Seule source de cette config : plus de fichier `.txt` pour les machines. Pour copier-coller, retirer le prompt `root@G26:~#`.

```bash
# =====================================================================
# G26 - Client prive du site n - Debian 12 - configuration a chaud (root)
# Authentification 802.1X (RADIUS de S26) puis adresse par DHCP
# =====================================================================
# ---------- 802.1X (wpa_supplicant, EAP-MD5) ----------
root@G26:~#ip link set eth0 up
root@G26:~#cat > /etc/wpa_supplicant/monradius.conf <<'EOF'
ctrl_interface=/var/run/wpa_supplicant
ctrl_interface_group=0
ap_scan=0
network={
    key_mgmt=IEEE8021X
    eap=MD5
    identity="g26"
    password="G26pass!"
    eapol_flags=0
}
EOF
root@G26:~#wpa_supplicant -B -D wired -c /etc/wpa_supplicant/monradius.conf -i eth0

# ---------- Adressage par DHCP (serveur S26, relais R26) ----------
root@G26:~#dhclient -v eth0
root@G26:~#ip addr show eth0
root@G26:~#ip route
```
