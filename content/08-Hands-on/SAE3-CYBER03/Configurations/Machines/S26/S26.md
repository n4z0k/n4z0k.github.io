# S26
---

> Serveur · Debian 12 · site n · [[SAE3-CYBER03 - Accueil|Accueil]]

## Rôle

Serveur du site n (réseau sans VLAN). Mêmes services que [[S25]] : web, SSH, FTP, vidéo (TCP 8080), DHCP du réseau privé 192.168.26.0/24 et RADIUS. Le NAS déclaré est [[SW26-2]] (150.150.26.250), joint via [[R26]].

## Adresses

- eth0 : 50.50.26.1/24
- passerelle : 50.50.26.254

## Voisins

- [[SW26-1]] — eth0 ↔ port 1
- [[R26]] — passerelle par défaut 50.50.26.254 (E1/0)

## Configuration (avec prompt)

> Seule source de cette config : plus de fichier `.txt` pour les machines. Pour copier-coller, retirer le prompt `root@S26:~#`.

```bash
# =====================================================================
# S26 - Serveur du site n - Debian 12 - configuration a chaud (root)
# Services : Web, SSH, FTP, DHCP (reseau prive), RADIUS (802.1X), video
# =====================================================================
# ---------- Adressage IP (a chaud) ----------
root@S26:~#ip link set eth0 up
root@S26:~#ip addr add 50.50.26.1/24 dev eth0
root@S26:~#ip route add default via 50.50.26.254 dev eth0
root@S26:~#ip addr show eth0
root@S26:~#ip route

# ---------- Web (Apache) ----------
root@S26:~#cat > /var/www/html/index.html <<'EOF'
<!DOCTYPE html>
<html lang="fr"><head><meta charset="utf-8"><title>S26</title></head>
<body><h1>Serveur web S26 - Site n (50.50.26.1)</h1><p>SAE3-CYBER03</p></body></html>
EOF
root@S26:~#systemctl restart apache2

# ---------- SSH ----------
root@S26:~#systemctl restart ssh

# ---------- FTP (vsftpd, mode passif 40000-40100 ouvert dans l'ACL de R26) ----------
root@S26:~#cat > /etc/vsftpd.conf <<'EOF'
listen=YES
listen_ipv6=NO
anonymous_enable=NO
local_enable=YES
write_enable=YES
local_umask=022
chroot_local_user=YES
allow_writeable_chroot=YES
connect_from_port_20=YES
pasv_enable=YES
pasv_min_port=40000
pasv_max_port=40100
pam_service_name=vsftpd
secure_chroot_dir=/var/run/vsftpd/empty
EOF
root@S26:~#useradd -m -s /bin/bash ftpuser
root@S26:~#echo 'ftpuser:Ftp26pass!' | chpasswd
root@S26:~#systemctl restart vsftpd

# ---------- DHCP du reseau prive 192.168.26.0/24 (relaye par R26) ----------
root@S26:~#cat > /etc/default/isc-dhcp-server <<'EOF'
INTERFACESv4="eth0"
INTERFACESv6=""
EOF
root@S26:~#cat > /etc/dhcp/dhcpd.conf <<'EOF'
authoritative;
default-lease-time 3600;
max-lease-time 7200;
subnet 50.50.26.0 netmask 255.255.255.0 {
}
subnet 192.168.26.0 netmask 255.255.255.0 {
    range 192.168.26.1 192.168.26.128;
    option routers 192.168.26.254;
    option broadcast-address 192.168.26.255;
}
EOF
root@S26:~#systemctl restart isc-dhcp-server

# ---------- RADIUS (FreeRADIUS, methode du TP5) : NAS SW26-2 (150.150.26.250) + compte 802.1X g26 ----------
root@S26:~#cat >> /etc/freeradius/3.0/clients.conf <<'EOF'
client 150.150.26.250 {
    shortname = SW26-2
    secret    = RadiusSae3
    nastype   = cisco
}
EOF
root@S26:~#sed -i '1i g26 Cleartext-Password := "G26pass!"' /etc/freeradius/3.0/users
root@S26:~#systemctl restart freeradius
# Pour le debogage (comme au TP5) : systemctl stop freeradius puis freeradius -X

# ---------- Video HTTP sur le port 8080 (classe VIDEO de la QoS) ----------
root@S26:~#useradd -r -m -s /usr/sbin/nologin streamer
root@S26:~#mkdir -p /srv/video
root@S26:~#ffmpeg -y -f lavfi -i testsrc=duration=600:size=640x360:rate=25 -c:v libx264 /srv/video/demo.mp4
root@S26:~#chown -R streamer: /srv/video
root@S26:~#runuser -u streamer -- cvlc --loop /srv/video/demo.mp4 --sout '#standard{access=http,mux=ts,dst=:8080}' &

# ---------- Verification ----------
root@S26:~#ss -lntup
```
