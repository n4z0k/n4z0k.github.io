# D26
---

> Client · Debian 12 · site n · [[SAE3-CYBER03 - Accueil|Accueil]]

## Rôle

Client **public** du site n (VLAN 150), adresse fixe, sans NAT. Seul type de poste autorisé à lire la vidéo de [[S25]] (ACL `PROTECT-SERVEURS`), et machine de test principale de la recette.

## Adresses

- eth0 : 150.150.26.1/24
- passerelle : 150.150.26.254

## Voisins

- [[SW26-2]] — eth0 ↔ ports 11-20 (VLAN 150)
- [[R26]] — passerelle par défaut 150.150.26.254 (Fe0/0.150)

## Configuration (avec prompt)

> Seule source de cette config : plus de fichier `.txt` pour les machines. Pour copier-coller, retirer le prompt `root@D26:~#`.

```bash
# =====================================================================
# D26 - Client public du site n - Debian 12 - configuration a chaud (root)
# =====================================================================
# ---------- Adressage IP (a chaud) ----------
root@D26:~#ip link set eth0 up
root@D26:~#ip addr add 150.150.26.1/24 dev eth0
root@D26:~#ip route add default via 150.150.26.254 dev eth0
root@D26:~#ip addr show eth0
root@D26:~#ip route
```
