# S25
---

> Serveur · Debian 12 · site m · [[SAE3-CYBER03 - Accueil|Accueil]]

## Rôle

Serveur du site m (VLAN 50). Héberge le **web** (Apache), **SSH**, **FTP** (vsftpd, passif 40000-40100), la **vidéo** (TCP 8080), le **DHCP** du réseau privé 192.168.25.0/24 (isc-dhcp-server) et le **RADIUS** FreeRADIUS pour l'authentification 802.1X des ports de [[SW25]].

## Adresses

- eth0 : 50.50.25.1/24
- passerelle : 50.50.25.254

## Voisins

- [[SW25]] — eth0 ↔ ports 21-23 (VLAN 50)
- [[R25]] — passerelle par défaut 50.50.25.254 (Fe0/0.50)

## Configuration (avec prompt)

> Seule source de cette config : plus de fichier `.txt` pour les machines. Pour copier-coller, retirer le prompt `root@S25:~#`.

```bash
# =====================================================================
# S25 - Serveur du site m - Debian 12 - configuration a chaud (root)
# Services : Web, SSH, FTP, DHCP (reseau prive), RADIUS (802.1X), video
# =====================================================================
# ---------- Adressage IP (a chaud) ----------
root@S25:~#ip link set eth0 up
root@S25:~#ip addr add 50.50.25.1/24 dev eth0
root@S25:~#ip route add default via 50.50.25.254 dev eth0
root@S25:~#ip addr show eth0
root@S25:~#ip route

# ---------- Web (Apache) ----------
root@S25:~#cat > /var/www/html/index.html <<'EOF'
<!DOCTYPE html>
<html lang="fr"><head><meta charset="utf-8"><title>S25</title></head>
<body><h1>Serveur web S25 - Site m (50.50.25.1)</h1><p>SAE3-CYBER03</p></body></html>
EOF
root@S25:~#systemctl restart apache2

# ---------- SSH ----------
root@S25:~#systemctl restart ssh

# ---------- FTP (vsftpd, mode passif 40000-40100 ouvert dans l'ACL de R25) ----------
root@S25:~#cat > /etc/vsftpd.conf <<'EOF'
listen=YES
listen_ipv6=NO
anonymous_enable=NO
local_enable=YES
write_enable=YES
local_umask=022
chroot_local_user=YES
allow_writeable_chroot=YES
connect_from_port_20=YES
pasv_enable=YES
pasv_min_port=40000
pasv_max_port=40100
pam_service_name=vsftpd
secure_chroot_dir=/var/run/vsftpd/empty
EOF
root@S25:~#useradd -m -s /bin/bash ftpuser
root@S25:~#echo 'ftpuser:Ftp25pass!' | chpasswd
root@S25:~#systemctl restart vsftpd

# ---------- DHCP du reseau prive 192.168.25.0/24 (relaye par R25) ----------
root@S25:~#cat > /etc/default/isc-dhcp-server <<'EOF'
INTERFACESv4="eth0"
INTERFACESv6=""
EOF
root@S25:~#cat > /etc/dhcp/dhcpd.conf <<'EOF'
authoritative;
default-lease-time 3600;
max-lease-time 7200;
subnet 50.50.25.0 netmask 255.255.255.0 {
}
subnet 192.168.25.0 netmask 255.255.255.0 {
    range 192.168.25.1 192.168.25.128;
    option routers 192.168.25.254;
    option broadcast-address 192.168.25.255;
}
EOF
root@S25:~#systemctl restart isc-dhcp-server

# ---------- RADIUS (FreeRADIUS, methode du TP5) : NAS SW25 (50.50.25.250) + compte 802.1X g25 ----------
root@S25:~#cat >> /etc/freeradius/3.0/clients.conf <<'EOF'
client 50.50.25.250 {
    shortname = SW25
    secret    = RadiusSae3
    nastype   = cisco
}
EOF
root@S25:~#sed -i '1i g25 Cleartext-Password := "G25pass!"' /etc/freeradius/3.0/users
root@S25:~#systemctl restart freeradius
# Pour le debogage (comme au TP5) : systemctl stop freeradius puis freeradius -X

# ---------- Video HTTP sur le port 8080 (classe VIDEO de la QoS) ----------
root@S25:~#useradd -r -m -s /usr/sbin/nologin streamer
root@S25:~#mkdir -p /srv/video
root@S25:~#ffmpeg -y -f lavfi -i testsrc=duration=600:size=640x360:rate=25 -c:v libx264 /srv/video/demo.mp4
root@S25:~#chown -R streamer: /srv/video
root@S25:~#runuser -u streamer -- cvlc --loop /srv/video/demo.mp4 --sout '#standard{access=http,mux=ts,dst=:8080}' &

# ---------- Verification ----------
root@S25:~#ss -lntup
```
