# G25
---

> Client · Debian 12 · site m · [[SAE3-CYBER03 - Accueil|Accueil]]

## Rôle

Client **privé** du site m (VLAN 192). Doit s'authentifier en **802.1X** (wpa_supplicant, EAP-MD5) auprès de [[S25]] avant d'obtenir une adresse par DHCP. Ses accès vers l'autre site passent par le NAT de [[R25]] (si l'adresse est ≤ .63).

## Adresses

- eth0 : DHCP 192.168.25.1 à .128
- passerelle : 192.168.25.254

## Voisins

- [[SW25]] — eth0 ↔ ports 1-10 (VLAN 192, 802.1X)
- [[R25]] — passerelle par défaut 192.168.25.254 (Fe0/0.192)

## Configuration (avec prompt)

> Seule source de cette config : plus de fichier `.txt` pour les machines. Pour copier-coller, retirer le prompt `root@G25:~#`.

```bash
# =====================================================================
# G25 - Client prive du site m - Debian 12 - configuration a chaud (root)
# Authentification 802.1X (RADIUS de S25) puis adresse par DHCP
# =====================================================================
# ---------- 802.1X (wpa_supplicant, EAP-MD5) ----------
root@G25:~#ip link set eth0 up
root@G25:~#cat > /etc/wpa_supplicant/monradius.conf <<'EOF'
ctrl_interface=/var/run/wpa_supplicant
ctrl_interface_group=0
ap_scan=0
network={
    key_mgmt=IEEE8021X
    eap=MD5
    identity="g25"
    password="G25pass!"
    eapol_flags=0
}
EOF
root@G25:~#wpa_supplicant -B -D wired -c /etc/wpa_supplicant/monradius.conf -i eth0

# ---------- Adressage par DHCP (serveur S25, relais R25) ----------
root@G25:~#dhclient -v eth0
root@G25:~#ip addr show eth0
root@G25:~#ip route
```
